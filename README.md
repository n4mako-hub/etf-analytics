# 📊 ETF Performance Analytics & Portfolio Tracker

A lightweight and powerful web app built with **Streamlit** and **Python** to monitor your favorite ETFs, analyze historical data, and spot investment opportunities.

### 🚀 Key Features:
- **Customizable Watchlist:** Easily add instruments using ISIN or Yahoo Finance tickers.
- **Category Grouping:** Manage and filter your ETFs sorted by asset class (Global Equity, Bonds, Money Market, etc.).
- **Interactive Charts:** Visualize normalized performance (Base 100) or historical prices with flexible timeframes using Plotly.
- **Cycles & Drawdown Analysis:** Evaluate historical resilience, maximum drawdowns, and best/worst calendar years.
- **Pullback Scanner ("Buy the Dip"):** Quickly identify instruments experiencing a temporary correction from recent highs.
- **Mobile-Friendly:** Fully optimized for seamless use on both desktop and smartphones.
